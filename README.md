# Inventa

Inventario y pedidos para tu negocio. Next.js 16 + Supabase.

## Puesta en marcha

```bash
npm install
cp .env.example .env.local   # rellena la URL y la clave publicable de Supabase
npm run dev
```

## Comandos

```bash
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm test           # Vitest
npm run build      # build de producción
```
